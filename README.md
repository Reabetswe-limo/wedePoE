Follow these sequential steps to open, execute, and verify the interactive elements across local workspace instances or live production servers:

 1. Local Workspace Execution
1. Clone this repository or download all source files into a single project root folder.
2. Ensure the structural path matching remains intact:
 HTML pages (`index.html`, `about.html`, `membership.html`, `shop.html`, `contact.html`) must rest directly inside the root level directory.

Technical Reference & Architecture

This application utilizes a structured structural program stack to deliver user interaction while maintaining zero external framework dependencies:

Core Programming Languages
HTML5 Semantic Structure: Incorporates strict layout landmarks (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) to maximize clean parsing and search accessibility compliance indexes.
CSS3 Flexible Styling Grid: Provides visual layouts utilizing custom responsive layout blocks, color palettes, and typography grids styled to adapt fluidly from mobile viewport metrics upwards.
Vanilla JavaScript (ES6+): Formulates all interaction patterns using modular functions, native conditional structures, and clean variable definitions to guarantee light page rendering execution times.

Component Feature Hooks
1. Dynamic Content Filter Engine: Captures text entry keystrokes on `shop.html`, matching values against product data terms to display relevant stock variations dynamically.
2. Immersive Image Lightbox: Attaches event logic to cross-page elements (`about.html`, `shop.html`), launching a modal dark-room container shroud to view assets in full dimensions.
3. Interactive Branch Finder Map: Executes toggle triggers inside the contact section to update hours, directions, and student transit distances without reloading the page.
4. Form Validation Workflows: intercept input strings across entry fields (`enquiryForm`, `contactForm`), verifying required spaces and structurally sound email configurations before displaying simulated server feedback messages.
